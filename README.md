Bank Loan Analysis Report

📌 Project Overview
This project provides a comprehensive analysis of bank lending activities to monitor performance, assess loan portfolio health, and identify trends. The goal is to enable data-driven decision-making for lending strategies using SQL, Excel, and AI-driven presentation tools.


📊 Key Performance Indicators (KPIs)
The analysis focuses on several critical metrics:

Total Loan Applications: Tracking MTD and Month-over-Month (MoM) changes.

Total Funded Amount: Monitoring the disbursement of funds and MoM trends.

Total Amount Received: Assessing cash flow and repayment status.

Average Interest Rate & DTI: Evaluating the overall cost of the portfolio and borrower financial health.


📉 Good Loan vs. Bad Loan Analysis
To assess the quality of the loan portfolio, the report distinguishes between:

Good Loans: Applications with a status of 'Fully Paid' or 'Current'.

Bad Loans: Applications categorized as 'Charged Off'.


🚀 Tech Stack Used
SQL (SSMS): Used for data cleaning and querying complex KPIs.

Microsoft Excel: Used for creating Pivot Tables and initial data grid views.

Gamma (AI): Used to generate an Executive Summary and professional presentation.


📂 Project Structure
financial_loan.sql: Contains all SQL queries for KPI calculations.

Pivot_Table.xlsx: Excel-based analysis and data grid views.

Financial-Loan-Report-Executive-Summary.pdf: A visual summary of findings generated via Gamma.

financial_loan.csv: The raw dataset used for this project.



💡 Key Insights & Chart Requirements
The report includes visual breakdowns of:

Monthly Trends: Identifying seasonality in lending.

Regional Analysis: Mapping lending activity by state.

Loan Term & Purpose: Understanding why and for how long borrowers seek financing.

Home Ownership & Employment: Analyzing how borrower profiles impact disbursements.
